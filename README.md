# Dotverse

A free, private desktop app for collecting and connecting ideas: freeform boards for notes, images, video, audio and 3D models, all linked together in a living map.

**Install:** download `Dotverse-Setup.exe` and run it. Windows shows "Windows protected your PC" the first time because the installer isn't code-signed — click **More info → Run anyway**. It installs per user (no administrator password) and needs nothing else.

- **Universes** hold your boards; every board is a **dot** on a map. Draw lines between dots to show how ideas relate.
- **Boards** are infinite canvases for notes, checklists, links, pictures, video, audio, documents and 3D models.
- **Shift+A** opens the create wheel on any board.
- Everything is saved on **your own computer**. Optional **Sign in with Google** keeps your universes the same on all your computers, stored in a private area of your own Google Drive — nothing is hosted by anyone else.
- Windows 10/11 · free · no ads, no tracking · MIT licence.
